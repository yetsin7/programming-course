# Programming Course Archive

The original combined repository has been split into two independent projects.
Each project now has its own source tree, interface, validation workflow,
deployment, Git history, and repository.

| Course | Repository | Published interface |
| --- | --- | --- |
| Python for teenagers and adults | [python-course](https://github.com/yetsin7/python-course) | [Open course](https://yetsin7.github.io/python-course/) |
| Python for children | [python-for-children](https://github.com/yetsin7/python-for-children) | [Open course](https://yetsin7.github.io/python-for-children/) |

The local `python/` and `python-for-children/` directories are intentionally
ignored here because each directory is now an independent Git repository.
