# Child Course: Python Club

This Spanish-language course introduces Python through 32 guided missions for a
child around nine years old. Each mission presents one idea, a short code
fragment with an explanation, a challenge to solve in an external editor, a
comprehension question, and a progress star.

## Start the course

Open `index.html` in a browser. Reading the missions and saving quiz progress do
not require an application server or an account.

## Practice the code

Install Python, write your own solution in a `.py` file using VS Code or any
other text editor, and run it from the editor's integrated terminal, PowerShell,
or Command Prompt. The mission fragment is a clue, not a complete solution:

```powershell
python my-exercise.py
```

When a program calls `input()`, type the response in the terminal after running
the file. Keep each attempt in a separate, descriptively named file so the child
can compare versions and recover earlier ideas.

## Mission route

- Stage 1, missions 1–12: instructions, text, numbers, variables, input,
  decisions, loops, functions, lists, errors, and a first small game.
- Stage 2, missions 13–22: returned values, modules, exceptions, files, CSV,
  version control, tests, classes, types, and algorithms.
- Stage 3, missions 23–32: dates, money, databases, safe changes, design, APIs,
  applications, security, integration tests, and a final project.

The browser stores quiz progress locally. Clearing browser storage or changing
browsers does not transfer that progress automatically.
